
# Student Grade Manager

A console-based Java application that calculates student
performance, percentages, grades, and pass/fail results.

## Features

- Accepts a student's name and marks for five subjects
- Calculates total marks and percentage
- Assigns grades based on percentage
- Displays the final result as PASS or FAIL
- Validates marks to ensure they are between 0 and 100

## Technologies Used

- Java
- Java Scanner for user input
- Conditional statements and loops
- Methods for grade calculation

## Grading Criteria

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89% | A |
| 70–79% | B |
| 60–69% | C |
| 40–59% | D |
| Below 40% | F |

## Getting Started

### Prerequisites

Install Java JDK and ensure `java` and `javac`
are available in your terminal.

### Run the Application

1. Clone this repository:

   `git clone https://github.com/agrawaladitya1031-ux/StudentGradeManager.git`

2. Open the project folder:

   `cd StudentGradeManager`

3. Compile the program:

   `javac StudentGradeManager.java`

4. Run the application:

   `java StudentGradeManager`
